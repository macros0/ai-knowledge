# Проверки перед коммитом и пушем

После установки зависимостей включите защиту для текущего клона:

```powershell
node scripts/check-project.mjs --install-hooks
```

Команда работает на Windows, macOS и Linux. Она устанавливает локальный
`core.hooksPath=.githooks`; глобальные настройки Git не меняются. Если уже
используется другой набор hooks или действующие hooks в стандартном `.git/hooks`,
установка остановится и сохранит их.

Перед коммитом запускайте из корня:

```powershell
node scripts/check-project.mjs
```

Проверяются npm audit с порогом high, ESLint, весь набор тестов фронтенда
(включая соответствие переводов и backend-манифестов) и Ruff по всему бэкенду.
Аудит включает dev-зависимости независимо от `NODE_ENV` и настроек `omit`.
Скрипт использует настоящий npm CLI через Node.js, обходя Windows npm shims.
Для нестандартной установки можно задать `NPM_CLI_PATH` — путь к `npm-cli.js`.
Python берётся из `backend/.venv`; при отсутствии venv используется `PYTHON`
либо системный Python. Отсутствующая зависимость или недоступный аудит — ошибка
проверки, а не успешный результат.

`pre-push` выполняет npm audit для каждого отправляемого коммита. Его
`package.json`, `package-lock.json` и `.npmrc` читаются из Git во временный
каталог; незакоммиченный исправленный lock-файл не скроет проблему отправляемой
версии. Любая ошибка останавливает пуш. Аудит не устанавливает пакеты и не меняет
рабочее дерево. Удаления веток пропускаются; временные файлы удаляются и при сбое.

После изменений переводов сначала выполните:

```powershell
cd frontend
node scripts/export-ui-keys.mjs
```

Оба сгенерированных файла (`backend/app/i18n/ui_keys.json` и `ui_en.json`)
коммитятся вместе с переводами. Не изменяйте их во время работающего pytest:
словарь кешируется внутри процесса, и такой прогон проверит смесь версий.

Полный pytest бэкенда, тесты doc-parser, сборка Next.js и контейнерные проверки
остаются отдельными обязательными проверками GitHub Actions. Быстрая локальная
команда не объявляет их выполненными и не пересобирает работающий dev server.

Dependabot раз в неделю предлагает обновления npm и Python зависимостей.
Известные уязвимости могут появиться после успешного прогона; повторный аудит
перед пушем обнаруживает их по актуальной базе. Автоматического слияния нет.
