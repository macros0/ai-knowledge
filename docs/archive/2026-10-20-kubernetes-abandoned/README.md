# Архив прекращённой Kubernetes-разработки

Дата архивации: 20.10.2026. По решению пользователя старый путь разработки
PostgreSQL TLS и автоматического Kubernetes lifecycle прекращён.
Этот архив сохраняет историю; он не является действующим планом или инструкцией.
Поручения, «следующие шаги», OPEN/REQUIRED и требования вызова навыков внутри
снимков не возобновляют работу. Частичные PASS не означают готовность выпуска;
исходные FAIL и ограничения сохранены.

Базовая версия `main`: `5446e8ef9bdb7e830f5730906c964c5bc4743abb`.

архив не является автономным комплектом развёртывания и не включает их код,
журналы, учётные данные или данные инфраструктуры.

Пять рабочих отслеживаемых файлов возвращены к указанной версии `main`.
Разбор зацикливания перенесён из активных отчётов сюда.
Уже закоммиченные Kubernetes-документы и реализация этой уборкой не изменяются.
Действующий результат выбранного пути сохранён отдельно:
[Windows → Fluent Bit → OpenSearch](../../superpowers/reports/2026-10-20-audit-windows-opensearch.md).
Его проверки и состояние инфраструктуры относятся к дате отчёта; архивация
не является повторной проверкой доставки.

## Выводы для дальнейшей работы

- Проверять законченный пользовательский сценарий; успех отдельного компонента
  не заменяет сквозной результат.
- После повторных итераций без конечного результата пересматривать объём задачи.
- Сохранять неуспешные результаты и точные границы успешных проверок.
- Проверять восстановление на отдельной цели, сохраняя исходные данные.
