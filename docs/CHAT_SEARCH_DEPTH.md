# Глубина поиска в чате

В режимах «Найти источники», «Быстрый ответ» и «Полное исследование» глубина
задаёт максимум итоговых фрагментов после объединения и фильтрации. Она не
задаёт число документов: один документ может дать несколько фрагментов.

Поиск начинает с N кандидатов, затем при необходимости запрашивает 2N, 4N
и 8N. На каждом проходе применяются те же фильтры документов, языка, тегов,
писем, области поиска и лексических совпадений. Итог ограничивается N
фрагментами после этих операций. Эмбеддинг запроса вычисляется один раз.

Если кандидаты исчерпаны, возвращаются все подходящие фрагменты, даже если их
меньше N. Если внутренний предел кандидатов достигнут раньше, выдача также
может быть короче; `search_limit_reached=true` предупреждает о возможных
дополнительных источниках. Увеличение глубины расширяет и предел кандидатов.
Все проходы учитывают отмену запроса и общий таймаут.

Ограничение контекста LLM применяется отдельно и не сокращает список найденных
источников. Старый API без `response_mode` сохраняет прежнее поведение `top_k`.
