# Сопровождение руководства пользователя

Актуальная редакция: 18.10.2026. Пользовательские материалы:

- Русский: [Markdown](OKF_User_Guide.md), [PDF](OKF_User_Guide.pdf).
- English: [Markdown](OKF_User_Guide_EN.md), [PDF](OKF_User_Guide_EN.pdf).
- Снимки интерфейса: `assets/user-guide/`, отдельный комплект для каждого языка.
- Корневая папка `screenshots/` содержит точные копии всех 20 снимков из обеих инструкций с теми же именами. При обновлении иллюстраций синхронизируйте обе папки; README использует эти копии.

## Повторная сборка

Из корня репозитория, в Python с установленными `reportlab` и `pypdf`:

```powershell
python scripts/build-user-guides.py
```

Скрипт использует Arial из Windows Fonts либо DejaVu Sans из стандартного каталога Linux. Другой каталог можно передать через `--font-dir`. Оба PDF создаются из Markdown с оглавлением, закладками и встроенными шрифтами. Скрипт проверяет наличие заголовков и количество закладок. Снимки должны существовать до сборки.

Нумерация и идентификаторы `guide-01` … `guide-21` совпадают в двух языковых версиях. При изменении структуры обновляйте оба оглавления. При новой редакции обновите дату в обоих Markdown и в оформлении PDF в скрипте.

Старые `scripts/replace-guide-pdf-images.py` и `scripts/capture-doc-screenshots.mjs` относятся к прежней верстке и набору `screenshot-01.png` … `screenshot-13.png`: для новых инструкций их не применять. Актуальные иллюстрации имеют префиксы `ru-` и `en-`.

## Основания редакции

Текст сверялся с текущими компонентами и переводами интерфейса и с проверками прав backend. Основные группы исходников:

| Сценарии | Компоненты в `frontend/src/components/` |
|---|---|
| Навигация и роли | `Nav.jsx`, панели соответствующих разделов; проверки доступа backend |
| Вопросы, источники, область поиска, история | `ChatPanel`, `ChatFilters`, `ChatSources`, `ChatSearchScope`, `ChatSourceAssessment`, `ChatHistoryPanel` |
| Загрузка, вложения, обновление публикации | `DocumentUploadPanel`, `DocumentProcessingScopeDialog`, `DocumentList`, `DocumentQueueStatus` |
| Просмотр, ячейки и маркировка | `DocumentSources`, `DocumentTables`, `TableSourceView`, `DocumentMarkupModal` |
| Справочники и переводы | `DevelopmentPanel`, `TagManagerModal`, `GlossaryPanel`, `LanguagesPanel` |
| Диагностика и история пользователей | `DiagnosticsPanel`, `DiagnosticClientReporter`, `AdminChatHistoryPanel` |

В работающем интерфейсе под ролью Editor проверены список документов, загрузка, настройки вопросов, просмотр и маркировка. Иллюстрации получены в русской и английской локализации 18.10.2026. В них используется ранее загруженное вводное руководство о самом сервисе: его содержимое не служит описанием текущего продукта.

Дополнительно под ролью Admin просмотрены существующие термины, алиасы и правила диапазонов инфотипов. Форма нового термина заполнена учебным примером и очищена без сохранения. По запросу «ИТ 0295» выполнен поиск источников: на момент снимка один документ и семь фрагментов. Добавлены по шесть снимков для каждого языка (всего по десять иллюстраций в руководстве). В разделе 11 описано исключение из письма копии отдельно загруженного файла.

Остальные администраторские сценарии сверены по исходникам и переводам. Массовые действия, запуск генерации, изменение корпуса/справочников и диагностический сбор ради инструкции не выполнялись. Поисковые запросы сохраняются штатной историей приложения. Это проверка документации, а не приемка всех операций приложения.

## Проверка перед выпуском

1. Сопоставить инструкции и подписи с актуальным интерфейсом и правами.
2. Проверить эквивалентность двух языковых версий, ссылки и пути к снимкам.
3. Собрать оба PDF; проверить оглавление, закладки и извлечение кириллицы.
4. Отрендерить все страницы и просмотреть таблицы, переносы, поля и иллюстрации.
5. Публиковать Markdown, PDF и необходимые изображения вместе.
