## Реальный корпус и интерфейс

Проверены authenticated UI → Next proxy → /api/chat/stream → Qwen, появление
текста до завершения, финальные кликабельные цитаты и история.
Вопрос о кнопке «Считать из ИТ» в ZPRP_DISABILITY_CHLD дал правильный ответ:
HRPAYRU_FSSDP_APL4, корректировочный режим, файл из ИТ 3273.
Ответ вручную сопоставлен с сохранённым концептом.

На обзорном вопросе выявлено смешение соседнего ЭЛН-раздела из concept+chunk.
Добавлен опциональный CHAT_FOCUS_NAMED_OBJECTS: только для ограниченных полных
форм обзорного вопроса с одним кодом используется точное имя и собственное
содержание концепта. Сравнения и уточнения проверены отрицательными тестами.
После изменения примесь ЭЛН исчезла.

Ограничение качества: в обзорном ответе модель всё же добавила неподтверждённую
фразу о файлах, «полученных от СФР». Источник говорит лишь о файле в ИТ 3273 /
файле для приложений СФР. Модель пригодна для проверенных задач извлечения и
точечных вопросов, но свободные обзоры нельзя считать эквивалентными по
точности более сильной модели. JSON schema ограничивает форму, не смысл.

Отмена проверена живьём: при активной генерации (slot 0, task 952) браузер
ушёл со страницы. Затем busy=false, запрос «Подробно перечисли все поля
и условия ZPRP_DISABILITY_CHLD.» отсутствует в chat_messages (count=0).
Три завершённых приёмочных запроса остались в истории demo.admin для сравнения.
