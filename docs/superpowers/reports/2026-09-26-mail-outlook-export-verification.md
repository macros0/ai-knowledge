# Реальный экспорт Outlook: локальная проверка

26.09.2026 пользователь подтвердил: предоставленный MSG сохранён непосредственно из Outlook через «Сохранить как → MSG». Это provenance со слов владельца файла; версия Outlook и отдельная экспортная операция не наблюдались агентом.

Повтор текущим `mail-sources-v21` через supervised spawn завершён exit0: `tests/tmp/mail-outlook-v21-r2/report.json`. Файл 64 512 байт, CFB signature; четыре блока, три source nodes — письмо и два вложения. Сохранены два attachment files. Русский текст извлечён, replacement character нет, warning codes пусты. SHA исходника сохранён только в локальном ignored отчёте. Проверка была только парсингом: внешняя LLM не вызывалась, исходное письмо/текст не добавлялись в Git или CI.

Эта проверка закрывает вопрос происхождения одного реального экспорта для M04. ANSI/public/synthetic fixture matrix подтверждена отдельными прежними Windows/Linux прогонами; данный частный файл не считается публичным CI fixture и не доказывает поддержку всех версий Outlook, RTF-only, IRM или encrypted/signed MSG.

Первый вспомогательный wrapper завершился ошибкой чтения нового report path после успешного парсинга; он непригоден как итоговый exit0 результат. Он также перезаписал старый локальный metadata report в `outlook-fixture-acceptance`; исторические цифры из него больше не используются как отдельное immutable доказательство. Исправленный r2 записывает только новую папку и отказывается перезаписывать существующий report. Продуктовый парсер и исходник не менялись.
