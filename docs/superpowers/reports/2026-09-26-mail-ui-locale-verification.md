## Воспроизведение и исправление

До изменения `LocaleContext.jsx`: Enter на переключателе RU→EN обновляет
меню и кнопку Show source, но оставляет «Весь документ» и русскую ссылку
назад. Reload переводит и эти элементы. Причина: серверные компоненты
читают cookie через `serverTranslator`, а переключатель менял только
клиентское состояние/cookie, не обновляя RSC.

После записи cookie в явном `changeLocale` добавлен `router.refresh()`.
Обычная перезагрузка страницы не требуется. Серверные переводы приходят
асинхронно: проверка ждёт нужного заголовка, мгновенная смена всего UI
в одном кадре не заявляется. Автоматический выбор языка при первом заходе
этим изменением отдельно не исправлялся и не проверялся.

## Дополнение: фокус окон подтверждения

В следующем browser проходе воспроизведён отдельный RED: окно точного дубля
открывается с фокусом на disabled upload-zone, Tab с последней кнопки уходит
на «Массовые действия» за оверлеем, Escape оставляет focus на body.
`Modal.jsx` раньше имел только Escape handler. Добавлены начальный фокус,
замыкание Tab/Shift+Tab, возврат фокуса инициатору и обработка только верхнего
диалога по DOM-порядку. Callback закрытия хранится отдельно, чтобы обновление
props не переустанавливало фокус. Снимок инициатора делается до commit, чтобы
дочерний autoFocus не заменил его; WeakMap сохраняет путь возврата при замене
одного окна другим, не удерживая удалённые DOM-узлы как сильные ключи.

Первый повтор ещё загружал старый Modal (`tabindex` отсутствовал); не считается
GREEN. После reload новый компонент подтверждён по DOM (`tabindex=-1`).
Окончательные проверки после последнего изменения:

- Точный дубль: начальный focus внутри окна; Tab с отмены возвращает к первой
  ссылке; Escape закрывает и возвращает фокус доступной upload-zone.
- Похожий synthetic EML (23→24 дня, сходство≈95%): начальный focus внутри,
  Shift+Tab с первого контрола идёт на последнее действие, Tab возвращается
  к первому. Enter на отмене закрывает окно и возвращает фокус загрузке.
  Подтверждение загрузки не нажималось; число видимых документов осталось16.
- Общий потребитель Modal: асинхронный bulk-preview16 сохраняет focus на
  отмене; переход к typed confirmation сохраняет autoFocus на пустом input.
  Tab с отмены пропускает disabled подтверждение и идёт в input. Escape
  возвращает в preview, повторный Escape — к исходной кнопке предпросмотра.
  Целевое число не вводилось, операция не подтверждалась, удаление и генерация
  не запускались. После reload выбор документов0, диалогов0, видимых документов16.

Артефакты: `modal-focus-red.json`, `modal-{exact,similar,replacement}-focus-final.json`,
`modal-similar-focus-final.png`, `modal-final-tests.log`, `modal-final-build.log`
в `tests/tmp/mail-ui-v20/`. Свежие **188 passed**, ESLint Modal/LocaleContext
exit0, финальный Next build exit0. Browser checks, а не Node suite, являются
доказательством нового поведения фокуса. Изменён общий Modal: другие его
потребители и одновременные вложенные окна не проверены исчерпывающе.
Вкладка теперь на списке документов, RU; тестовые диалоги закрыты.

## Граница результата

Это воспроизведённое исправление языка и перечисленные клавиатурные сценарии.
Фокусирование элемента через locator.press не заменяет полный проход Tab
по каждому контролу. Focus trap двух upload-окон и replacement сценарий
проверены выше. Полная проверка screen reader, одновременных вложенных окон,
SSR/hydration при первом заходе и всех страниц не выполнена: U01 остаётся
частичным. Общая приёмка также не завершена; A02/S07 и другие открытые
критерии остаются в матрице. Модели и флаг импорта не менялись.
