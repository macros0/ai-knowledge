# План изменения загрузки и массовых действий с документами

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Рекомендуемый способ — последовательная реализация в текущем чате; задачи затрагивают общие компоненты и состояние.

**Goal:** Убрать массовые операции без выделения и два одновременно раскрытых блока; сделать загрузку отдельным диалогом, а работу с выбранными документами — компактной контекстной панелью.

**Architecture:** `DocumentsPanel` владеет окном и состоянием загрузки независимо от списка. `DocumentList` владеет выделением, постоянно доступными командами выбора и контекстной `SelectionBar`. Изменение тегов и восстановление после перезапуска получают отдельные компоненты поверх существующих API и диалогов предпросмотра.

**Tech Stack:** Существующие Next.js, React, CSS, RU/EN i18n, `node:test`; без новых зависимостей, миграций и изменений поискового/генерационного backend.

**Spec:** Предложение в текущем чате от 01.10.2026; его решения и уточнения полностью зафиксированы ниже. Пользователь запросил составление плана; реализация этим документом не запускается.

**Уточнения пользователя при реализации 02.10.2026:** загрузка становится вкладкой вместо отдельного окна. Порядок верхних вкладок: «Документы», «Загрузить документы», «Корзина». `DocumentQueueStatus` сохраняет прежнее расположение в верхней строке и прежний текст. Состояние пачки и параметры живут в `DocumentsPanel`; список сохраняет выделение при переключении вкладок. Название компонента загрузки — `DocumentUploadPanel.jsx` вместо `DocumentUploadDialog.jsx`; шаги ниже про закрытие окна относятся к переключению вкладки. Модальное окно остаётся только для решения о похожем файле и массовых операций.

**Статус исполнения:** реализация и автоматические проверки выполнены; 284 frontend-теста, check-project и production build прошли. Браузерная приёмка после корпоративного входа остаётся неподтверждённой. Подробности и решения: `docs/superpowers/reports/2026-10-02-document-actions-progress.md`.

## Итоговый интерфейс и поведение

```text
Документы                                      [+ Загрузить документы]
[Список] [По тегам] [По разработкам]
Поиск и фильтры
[Выбрать на странице] [Выбрать все результаты]

Выбрано: 3   [Изменить теги] [Скачать исходники] [Ещё ▾] [Снять выделение]
☑ Документ…
☑ Документ…
☑ Документ…
```

- При `selectedIds.length === 0` контекстной панели нет вообще. Убрать отдельную кнопку «Массовые действия» и состояние `bulkOpen`; появление и исчезновение определяет выделение.
- Команды выбора остаются над списком при нулевом выделении. Не переделывать карточки в таблицу ради чекбокса заголовка. В группировках явно использовать «Выбрать показанные», если загружен весь отфильтрованный набор.
- В панели показывать «Выбрано: N» без знаменателя: выбранные документы могут находиться на нескольких страницах. Пагинация, сортировка и группировка сохраняют выделение. Изменение поискового запроса или фильтра очищает выделение; при поиске — уже при изменении ввода, до debounce. Асинхронный ответ «Выбрать все» от прежнего фильтра игнорируется.
- «Снять выделение» очищает и `selected`, и `filterSelectedIds`, закрывает меню. Начатая серверная операция от этого не отменяется.
- В «Ещё»: «Возобновить обработку», «Перегенерировать», «Удалить документы…» с текущими правами. Предпросмотр показывает применимые документы и причины пропуска, включая смешанные статусы. Не вычислять применимость всей выборки только по текущей странице.
- Действия, недоступные по роли/выключенной функции, скрыты. Превышение лимита оставляет видимую неактивную кнопку с доступным с клавиатуры пояснением. Лимиты брать из существующих настроек/`documentBulkLimits.mjs`; authoritative limits для генерации остаются в preview API.
- Загрузка открывается отдельным диалогом. Видны зона файлов и язык; теги и разработка — в «Дополнительных параметрах». Заданные дополнительные параметры кратко видны при сворачивании. Форматы: DOCX, XLSX, PDF, EML, MSG.
- Закрытие загрузки сохраняет параметры, выделение списка и текущую пачку. Рядом с кнопкой загрузки остаётся индикатор «Загрузка: N из M» и возможность открыть окно. Это счётчик передачи файлов, не процент серверной генерации.
- Восстановление после перезапуска — отдельное уведомление администратора: «Есть документы с прерванной обработкой» и «Посмотреть и возобновить». Оно не зависит от выделения и не входит в «Ещё».

## Review Focus

1. Закрытие загрузки между файлами и во время ожидания решения о похожем файле: пачка сохраняется, решение не теряется — задача 2.
2. Смена фильтра во время запроса выбора всех результатов: поздний ответ не восстанавливает старое выделение — задача 1.
3. Лимит одной операции не должен уменьшать выборку для другой; выбор на нескольких страницах не оценивается по последней странице — задачи 1 и 3.
4. Меню тегов через portal внутри модального окна: фокус и Escape работают без конфликта с focus trap — задачи 2 и 3.
5. Сбой проверки восстановления не означает отсутствие прерванных документов; обновившийся preview определяет окончательный набор — задача 4.
