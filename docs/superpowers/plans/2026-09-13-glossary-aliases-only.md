# Глоссарий: поиск по алиасам и отметки дублей

Запрос: скрыть технический код, исключить его из поиска; при совпадении
алиасов показывать противоречие и помечать обе карточки.

## Правила

- Новый технический идентификатор создаётся сервером; существующие сохраняются.
- Только явно сохранённые алиасы участвуют в распознавании и расширении.
  Код, вид термина и язык не создают дополнительные поисковые формы.
- Существующие автоматически созданные алиасы остаются видимыми обычными
  алиасами: их можно изменить, отключить и удалить. Новых служебных алиасов нет.
- Сравнение алиасов: NFC, регистр и пробельные последовательности; без
  транслитерации, перевода или автоматического отождествления IT/ИТ.
- Одинаковые алиасы разных карточек сохраняются. Дубли вычисляются из текущих
  алиасов, включая отключённые карточки, и снимаются после устранения совпадения.
- Неоднозначные алиасы временно исключаются из расширения с объяснением;
  уникальные алиасы и исходный запрос продолжают работать.
- Предварительная проверка при вводе дополняется проверкой сохранённых данных.
  Повтор алиаса внутри одной карточки отклоняется.
